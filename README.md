# Bloomy Games Bot 🎮

## التشغيل
- Build: `pip install -r requirements.txt`
- Start: `python bot.py`
- متغيرات البيئة:
  - `DISCORD_TOKEN` توكن البوت (مطلوب)
  - `DASH_PASSWORD` كلمة سر لوحة التحكم (مطلوب لفتح /dashboard)
- في Developer Portal فعّل **Message Content Intent**.
- الصلاحيات: Send Messages, Embed Links, Attach Files, Add Reactions, Read Message History (+ scope `applications.commands`).

## الألعاب
**فردية:** اسرع، فكك، شركة، اشبك، صحح، اعكس، عكس، جمع، مفرد، حرف، اعلام، عواصم، ضرب، طرح، ادمج
**جماعية:** روليت، هايد، لغم، وصل، مافيا، كراسي، اكس، حجره، تصويت
**أخرى:** متجر، حقيبتي، عملات، يومي، توب، نقاطي، تحويل @شخص 5، اعطاء @شخص 5، ايفنت، ايقاف، العاب
اكتب الاسم في الشات (مع البادئة لو محددة) أو استخدم `/games` و`/solo`.

## طريقة اللوبي (مثل البوت المرجعي)
رسالة فيها `@here` + عدّاد تنازلي + `(0 / 20)` + صورة اللعبة + أزرار: دخول / خروج / (المتجر والحقيبة للروليت) / الشرح.
تبدأ اللعبة تلقائياً لما يخلص الوقت (وقت اللوبي يتغير من اللوحة).
- **اكس:** يختار وضع (ضد شخص / ضد ذكاء اصطناعي).
- **حجره:** بطولة إقصائية (أزواج عشوائية، الفائز يتقدم، آخر واحد يفوز بنقطة).
- **هايد:** جولات، باحث عشوائي عنده 3 محاولات، اللي ينلقى يطلع.
- **تصويت:** على الألعاب الجماعية والفايزة تبدأ تلقائياً.

## أوامر الإدارة (سلاش)
`/setprefix` `/setrole` `/clearrole` `/addpoints` `/addcoins` `/resetpoints` `/setstatus` `/dashboard`

## لوحة التحكم
`https://رابط-خدمتك/dashboard` (المستخدم أي شي، كلمة السر = DASH_PASSWORD):
وقت كل لعبة، رفع/حذف صورة كل لعبة، وقت نقاش المافيا، طرد اللي ما يتفاعل، مكافأة اليومي.

## ملاحظة مهمة
البيانات (النقاط/العملات) في `data.json` والصور المرفوعة في `images/custom`.
على استضافة بدون قرص دائم (Render المجاني) تنمسح عند كل إعادة نشر — فعّل Persistent Disk أو اطلب ربط قاعدة بيانات.
